# 钉钉风格酒馆美化

署名 Lucas。禁止二改、二传及商用。

版本 1.0.3，已在本机 SillyTavern 1.19.0 检查。

这是独立的酒馆前端扩展。它提供钉钉电脑版风格的侧栏、会话列表、聊天气泡、输入区和日夜外观。消息区和发送控件仍由酒馆处理。没有修改酒馆核心文件。

## 已在本机安装

安装目录为 `C:\Users\45767\Desktop\SillyTavern\public\scripts\extensions\third-party\dingtalk-tavern`。

打开本地酒馆 `http://127.0.0.1:8000` 即可使用。其他已经打开的酒馆页面需要刷新。

## 日夜切换

- 侧栏底部的太阳或月亮按钮可以立即切换外观。手动切换后会固定为所选外观。
- 侧栏底部齿轮打开外观设置。也可以按 Alt + Shift + D。
- 按时间切换默认在 07:00 进入白天模式，在 19:00 进入夜晚模式，使用设备本地时间。
- 可以自定白天和夜晚开始的时间，也支持跨午夜的时段。两个时间不能相同。
- 跟随系统会响应系统的浅色和深色偏好。
- 时间模式每 15 秒检查一次。重新回到页面时也会检查。浏览器在后台休眠时可能延迟切换。

## 常用功能

- 左侧显示已有角色和群聊。点击会打开该角色最近的聊天记录。
- 搜索可以筛选角色名和最近消息摘要。
- 顶部图钉可以置顶或取消置顶当前会话。置顶分类只显示置顶项。
- 记录入口列出最近的聊天文件，可以进入指定记录。
- 工作台提供角色管理、API 设置、世界书、用户设定、生成设置、扩展和酒馆设置。
- 聊天气泡仍使用酒馆原生消息。消息编辑、更多操作、候选回复和停止生成的控件都保留。
- 小于 700 像素宽时，会话列表与聊天分别显示。聊天顶部的返回按钮可返回列表。

## 恢复原界面

在外观设置中点击恢复原来的界面。当前电脑原有的 Kindle 主题会恢复。

之后可以在酒馆的扩展设置中找到钉钉桌面聊天美化，点击启用钉钉美化再次开启。Kindle 主题下可先打开右上角更多菜单，再选择扩展程序。

插件启用期间会临时暂停这台电脑中已开启的已知主题，并隐藏它们残留的界面元素。原主题的文件和保存的选项仍保留。其他未识别的主题需要单独关闭，以免样式重叠。

## 在另一台电脑安装

1. 解压插件包。
2. 将整个 `dingtalk-tavern` 文件夹放入酒馆的 `public/scripts/extensions/third-party/` 目录。
3. 刷新酒馆页面。

ZIP 包用于本地文件安装。它不是 Git 仓库地址，不能直接粘贴到酒馆的从 Git 仓库安装窗口。
